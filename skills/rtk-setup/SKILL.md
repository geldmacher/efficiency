# RTK Setup

Use this skill for first installation, installation state, host integration, and checks after an external RTK update. For a request to update RTK itself, including an existing `/rtk-setup` update request, follow [rtk-update](../rtk-update/SKILL.md) instead. Use `rtk-filter-design` for output-filter work.

Before writing a user-facing result, read [the human communication contract](../efficiency/references/human-communication.md) once per task, unless it is already loaded.

Follow [shared integration guidance](references/integration.md) for identification, host selection, verification, and reporting. For a requested first installation, use [the shared lifecycle procedure](references/lifecycle.md). Inspection alone does not authorize installation or configuration changes.
